# sstiktok-assets

SSautomation TikTok akisinin urettigi karusel gorselleri burada tutulur.

Bu depo PUBLIC olmak zorunda: TikTok fotograf gonderisi gorselleri yalnizca
`PULL_FROM_URL` ile, sahipligi dogrulanmis bir alan adindan herkese acik
sekilde alir. Kod ve secret'lar ayri, private depoda.

Gorseller `posts/<calisma-id>/01.png` altina yazilir ve eski calismalar
otomatik temizlenir.
